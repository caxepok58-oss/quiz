# Пенза Квиз-бот

Telegram-бот на [aiogram 3](https://docs.aiogram.dev/), который раз в сутки собирает
расписание квиз-игр в Пензе на ближайший месяц из нескольких сайтов и по команде
показывает таблицу: дата, время, игра, место проведения.

## Источники данных

Найдены поиском (действующие квиз-сети, у которых есть отдельные страницы расписания по Пензе):

- **Квиз, плиз!** — https://penza.quizplease.ru/schedule
- **Клуб «60 секунд»** — https://club60sec.ru/quizgames/schedule/58/
- **Шейкер квиз** — https://penza.shakerquiz.ru/

Список источников — `bot/sources/__init__.py`, каждый источник — небольшой класс в
`bot/sources/`. Добавить ещё один сайт — три строки: новый файл-класс на основе
`HeuristicScheduleSource` + добавить его в `ALL_SOURCES`.

### Важно: парсер эвристический, требует калибровки

Этот бот собирался в среде без доступа в интернет (прокси блокирует произвольные
сайты), поэтому реальную вёрстку страниц выше проверить не удалось и точные CSS-селекторы
написать было нельзя. Вместо этого `bot/sources/heuristic.py` ищет в тексте страницы
русские даты/время по регулярным выражениям и берёт наименьший подходящий блок как
карточку одной игры — это переживает то, что разметка неизвестна, но менее точно, чем
селекторы под конкретный сайт.

После первого запуска бота там, где есть реальный интернет:

1. Выполните `/update` (только админ) — форсирует обновление всех источников.
2. Выполните `/sources` — покажет, сколько игр нашёл каждый источник и есть ли ошибки.
3. Если какой-то источник находит 0 игр или мусор — откройте его страницу в браузере,
   посмотрите вёрстку и либо подправьте регэкспы в `bot/text_parsing.py`, либо напишите
   для этого источника отдельный класс с точными селекторами вместо
   `HeuristicScheduleSource`.

Пока источник не откалиброван, есть надёжный запасной путь — ручное добавление игр
администратором (`/add_game`), оно не зависит от парсинга сайтов.

## Команды бота

- `/start` — приветствие и список команд.
- `/games` (или `/quizzes`) — таблица всех игр на ближайшие `LOOKAHEAD_DAYS` дней.
- `/sources` — статус последнего обновления каждого источника (сколько игр нашлось).
- `/update` — force-refresh всех источников (только админы, `ADMIN_IDS`).
- `/add_game ГГГГ-ММ-ДД ЧЧ:ММ Название | Место | Цена` — добавить игру вручную (админы).
- `/list_manual` — список вручную добавленных игр с их id (админы).
- `/del_game <id>` — удалить вручную добавленную игру (админы).

## Установка и запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# впишите в .env токен бота от @BotFather и свой Telegram id в ADMIN_IDS

python run.py
```

Переменные окружения (`.env`):

| Переменная      | Назначение                                   | По умолчанию   |
|-----------------|-----------------------------------------------|----------------|
| `BOT_TOKEN`     | Токен бота от @BotFather                      | —              |
| `ADMIN_IDS`     | Telegram id админов через запятую              | —              |
| `CITY_NAME`     | Название города в сообщениях                  | `Пенза`        |
| `TZ_NAME`       | Часовой пояс для расписания обновлений        | `Europe/Moscow`|
| `LOOKAHEAD_DAYS`| На сколько дней вперёд показывать игры        | `30`           |
| `SCRAPE_HOUR`   | В какой час (по TZ_NAME) обновлять данные раз в сутки | `6`    |
| `DB_PATH`       | Путь к файлу SQLite                           | `quizzes.db`   |

При старте бот сразу обновляет данные один раз, затем — каждый день в `SCRAPE_HOUR`.

## Данные и хранение

SQLite-файл (`DB_PATH`) с тремя таблицами:

- `events` — то, что нашли скрейперы (перезаписывается на каждое обновление, отдельно по источнику).
- `manual_events` — то, что руками добавил админ через `/add_game` (не трогается скрейпером).
- `source_status` — статус последнего запуска каждого источника, для `/sources`.

Игры с датой в прошлом чистятся автоматически при каждом ежедневном обновлении.
